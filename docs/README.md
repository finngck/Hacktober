Technische Setup-, Architektur- und Schnittstellendokumentation entsteht mit dem ersten bestätigten Implementierungsauftrag, soweit sie zum Arbeiten nötig ist. Es gibt dafür keine leeren Vorlagen oder vorsorgliche Verzeichnisstruktur.

Notion-Inhalte sind nicht automatisch beschlossen oder umgesetzt. Für einen Featureauftrag werden Quelle, konkreter Umfang und Abnahmekriterien festgehalten. Die technische Doku beschreibt anschließend das vorhandene Verhalten.
